# Bundled alert cues

These fixed assets are embedded in the native executable with `include_bytes!`.
They are never loaded from a UI-supplied path. Native validation checks a bounded
size, RIFF/WAVE header and pinned SHA-256 before decoding.

The white-bag cue was supplied by the owner from MIT-licensed RealmShark/Tomato. Its original
MIT notice is reproduced below and in the root NOTICE.md. Normalization
preserves its 1.497-second duration, an approved exception to the one-second rule.
The unprocessed original is vendored in
`originals/white_bag.wav` under that same license.

The four original Maxed cues are generated with the Python
standard library script `scripts/generate-alert-sounds.py`. Personal Best and Flawless each consist of
three 180 ms sine notes at amplitude 0.4, with a sin(pi*i/(n-1)) squared envelope
per note. Frequencies are 523.25/659.25/783.99 Hz (PB) and 659.25/783.99/1046.5 Hz (reserved flawless). The script uses explicit
little-endian samples and fixed sample counts. Generated cues are dedicated to
use under this repository's MIT license, with no third-party audio input.
Key Popped uses two descending notes at 880/587.33 Hz, each 1543 samples
(70 ms rounded down), with the same envelope and amplitude 0.25. Its peak is
-12.04 dBFS and RMS -19.31 dBFS, intentionally softer than the other cues.
The WAV is 6216 bytes including its 44-byte PCM header.

Chat message uses two ascending notes at 587.33/880 Hz, each 1543 samples, amplitude 0.2, shared by Whisper, Guild message and Party message. Run `python scripts/generate-alert-sounds.py chat_message` to reproduce it.

Flawless is reserved and cannot be selected for automatic or Test delivery.

Run `python scripts/generate-alert-sounds.py key_popped` to reproduce Key Popped.
It is generated directly at its final level. Repeated generation produces identical bytes.
Run `python scripts/normalize-alert-sounds.py` to reproduce the other bundled copies.
The stdlib-only normalizer reads the three unprocessed WAVs in `originals/`,
verifies their pinned SHA-256 values, and never uses the processed outputs as input.
No Git history or external download is required. The originals for Personal Best
and Flawless are generated by `scripts/generate-alert-sounds.py` under this
repository's MIT license; running that generator without a cue argument writes
unnormalized versions to this directory, so run the normalizer afterward.
The originals directory is regeneration input only, not a runtime sound source.

Flawless and personal best receive constant gain only, to -1.0 dBFS peak;
their RMS is -8.27 dBFS. White bag first receives peak normalization, then a
stereo-linked peak limiter: -16 dBFS ceiling after normalization to -1 dBFS,
1 ms look-ahead, 0.1 ms exponential attack and 50 ms exponential release.
Gain reduction is explicitly capped at 15 dB. The initial gain is primed from the first
look-ahead window. A final constant makeup gain normalizes its peak to -1.0 dBFS,
with RMS -17.07 dBFS, 7.51 dB above the original -24.58 dBFS RMS. Gain reduction follows one
shared envelope for both channels. There is no per-sample power curve, noise gate,
added signal or separate noise-floor lift; quiet material receives only the
limiter's gain and constant makeup.

The owner listened to and approved the previously bundled alert sounds (White Bag,
Personal Best, Key Popped and Flawless) on 2026-10-05,
including the white-bag transient reduction and makeup gain.

Normalization preserves sample count, rate, channels and duration. Tests require peak
at or below -0.9 dBFS and RMS in the -17.1 +/- 1 dB band for white bag and
the -8.3 +/- 3 dB band for PB/flawless. Key Popped must stay below -12 dBFS
peak, within -20 to -18.5 dBFS RMS, and under 150 ms; its hash, exact byte
count and mono 22050 Hz PCM16 header are checked alongside the other cues. The script prints
before/after measurements and hashes; repeated runs produce identical bytes.
