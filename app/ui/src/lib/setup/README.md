# Setup and Settings

Routes consume the shell-injected client and preview state. The shared session owns setup/settings reads, command errors and progress polling; late queries cannot overwrite newer selections. Live confirmation needs compatible accessible Npcap, ready assets, native confirmation and actual live capture outside demo/preview.

Recording is implemented: explicit opt-in, editable quota up to 1,000,000,000 bytes and native status/recovery. Asset replacement cancels and joins the preceding extraction. Alerts configure sound and notifications through guarded native commands. Updates remain manual; Npcap guidance does not download or elevate anything.

See [UI ownership](../../../../../docs/architecture/ui.md), [recording](../../../../../docs/architecture/recording.md), [alerts](../../../../../docs/architecture/alerts.md) and [testing](../../../../../docs/development/testing.md). Fixtures do not validate installed Npcap, WebView2 or persistence under real Windows failures.
